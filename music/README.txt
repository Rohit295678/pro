🎵 BACKGROUND MUSIC — How to add your song
=============================================

The website plays a soft background track while Rashi browses the site.

➡️  HOW TO ADD MUSIC
1. Find an MP3 you love (something romantic, soft, or her favourite song).
2. Rename the file to:    birthday.mp3
3. Drop it into this folder (the "music" folder you are reading this from).
4. Refresh the website. Music will start when she clicks "Start Celebration"
   (or after the first tap, due to browser autoplay rules).

The site also accepts these alternative formats (use any one):
   • birthday.mp3
   • birthday.m4a
   • birthday.ogg

➡️  WHERE TO GET FREE ROMANTIC MUSIC (no copyright issues)

   • Pixabay  →  https://pixabay.com/music/search/romantic/
   • Pixabay  →  https://pixabay.com/music/search/love/
   • Mixkit   →  https://mixkit.co/free-stock-music/
   • YouTube Audio Library  →  https://studio.youtube.com (free, login required)

All Pixabay tracks are free for personal use. Click any track → "Free Download".

➡️  RECOMMENDED MOOD
   Keywords to search: romantic piano, lo-fi love, soft piano, dreamy

➡️  TIP
   Keep the file under ~5MB so the site loads fast.
   If you want her favourite Bollywood/Hindi song, you can grab the MP3 from
   YouTube using a converter like y2mate.com or yt1s.com (personal use only).

That's it! The little floating music button in the top-right corner lets her
pause / play whenever she wants. 💕
